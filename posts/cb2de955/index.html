Arch Linux 使用体验 | 2026年，Linux适合日用了吗？

  • 前言：我必须承认，Windows是一件伟大的艺术品，算上弃船这年，我已经用了快10年的Windows操作系统，从Windows XP一路用到了Windows11,甚至有幸体验过Windows10的DEV版以及Windows11的DEV镜像泄漏版，可是说Windows几乎陪伴了我整个使用任何操作系统的周期，对我来说目前还没有哪一个操作系统的使用时长超过Windows,从家里的机箱到学校的多媒体机再到我现在的笔记本，全是Windows,他无疑是一件伟大的艺术品。当然，我也不会踩一捧一，无论哪个操作系统都有他优秀的地方.

咳咳，扯远了。如果你只想知道是否适合日用或者群体分化什么的，请自行利用大标签进行跳转.

首先，我用过什么

如果是局限于PC平台，我用的操作系统大体分为3类，Windows, Unix, Linux.

理论上Linux 也是 Unix 的一种，不过存在基于 Linux 的发行版，同时也存在基于 Unix 的发行版，所以还是分开好（）.

Windows

Windows系的不用多说，Windows XP, Windows 7, Windows 8, Windows 8.1 Windows 10, Windows 11, Windows Server 2012 R2, Windows Server 2025, 算上PE的话用过FirPE, Edgeless PE, U启通, U启动, U深度， WePE, 大白菜, 老毛桃什么的，全是时代的眼泪……

我的旧博客中写到“至少我认为我应该给这个世界留下点东西，至少是一些记忆.”，他们确实做到了，并且给我留下了无休止的回忆. 对我来说可惜的是，我回不到旧梦了…

看着这个PE列表，会不会感到回到了过去那个上网找好用PE来制作随身Windows的时代

我的第一台台式电脑是Windows XP，当时的P2P下崽器教会了我怎么正确下载软件才不会被P2P下崽器毒害。当时的电脑全是各种弹窗广告，而那时的我还蛮喜欢用360的软件管家的，因为那个时候，我只会用360软管去清理各种奇葩的软件，同时下载软件，这是避免下崽器的最好的方式

接触到PE以及重装这些东西，要归功于早的时候我的一台笔记本电脑，在那之前，我对系统这一方面的认知基本为0。。。那台笔记本是Windows10旧版，Cortana在那台电脑上甚至还能用，重装的理由很简单，我想清理垃圾软件。。。于是那时的我用了腾讯电脑管家软件管理里面的重装大师，于是就出现了一直重装到有问题的Windows版本，开机就弹报错。后面慢慢摸索，接触到了那堆PE,然后就是官方ISO烧录什么的……都是后面的事情了……
记得我当时还很喜欢看的一个UP较痕继痕迹

再早一些就是在手机上的 Limbo X86 跑过 Windows 95、98 之类的，又或者是 Termux 里跑的 Qemu 运行 Windows 7 什么的……

早的时候嘛，精力是花不完的，对任何事物探索的热情也是用不完的

因为10多年的使用，Windows配置可谓是手到擒来的，装系统、找开机自启的目录、分区，一般是我们这堆PE用户的基本操作了……卡了就重装系统，在那时大概挺流行，起码B站教重装的视频那时蛮多的.

Unix

这个类别对我来说其实蛮少的，映像里用过的Unix系统只有 IOS, MacOS, FreeBSD.
IOS 很常见了，iPhone的，那时我有台5s，有锁机，我天天去尝试破解他的锁，各种寻找工具去破解激活锁，当然最终成了.

MacOS 不是我有苹果笔记本，相比之下我用了一种更抽象的方式——黑苹果，那时四叶草引导很强大，能直接引导进黑苹果的恢复模式，安装黑苹果，然后我记得需要找各种驱动文件去修理驱动问题，当时一个触摸板问题我就找了快三天的驱动，最后没想到真修成功了.

FreeBSD 一言难尽，可能是因为没试过，我没见到里面有什么能用的包管理器，系统是进去了，WIFI没驱动，蓝牙没驱动，一切就像刚开始，什么都没有…

Linux

要说到这类的操作系统，我可就不困了.

Kali Linux

Kali Linux 是我的启蒙 Linux，当时看到B站上有用户宣传这个系统还是怎么的，看的手痒痒，于是就安装上了，Kali是我的第一个Linux操作系统，他让我看到了原来除了Windows、MacOS之外，还有一个用起来给我非常轻快感觉的操作系统.

的确，当时的Kali那个蓝色背景+黑色的Kali Logo的壁纸极为简洁，配上Xfce轻快，那个版本的Kali完全就是神.

我也确实在Kali上面用了一段时间，认识到了apt, sudo, ls, mkdir, curl, wget之类基础命令的，可以说，Windows是我的操作系统安装启蒙，那么Kali就是我的Linux命令启蒙.

是神，但是最终我还是用回去了 Windows, 原因就是当时的 LinuxQQ 界面极其复古，而那时的我找到的解决方式是 Wine, 但是那时的 Wine 或许是我不会配置，对我的日用软件来说，兼容性是真的极差，微信文字有问题，QQ用不了，换成TIM就会出现TIM崩溃…

那时的Linux生态不像今天这样百花绽开…

Ubuntu

在Kali后面，我的下一个系统是Ubuntu,他给我最大的映像就是安装界面那个提示音以及那只瞪着前方的老虎，还有整个紫色的界面.

不过Ubuntu我几乎没怎么用过，对那时的我来说，他看着非常臃肿，大概率因为Gnome把我劝退了（）

服务器系

往下，基本都是服务器用了. CentOS 7 Stream, CentOS 9 Stream, Ubuntu Server, OpenEuler, Debian…

软件系

  • WSL 上尝过 Oracle Linux, Arch Linux, Kali Linux
  • Termux 用tmoe弄proot容器试过Kali, Ubuntu, Debian
  • 同时，当时我建立了MC和谐服务器，她那时跑在一个名为AidLux的应用上面，那个本质上也是Debian，只不过他是Debian运行在Android上的实现，也是那时我见到了优秀的项目 FileBrowser 并沿用至今.
  • 还有就是，小小电脑的GXDE OS吸引了我一段时间.

国产系

早的时候试过UOS, 后面就是Deepin. 这两个系统都给了我眼前一亮的体验，但是终究还是因为各种界面Bug放弃了. 至于中科麒麟什么的，目前是没用过的，也不打算选择，界面不合我审美.

不过 我还是很希望国产操作系统起来的 毕竟方便的是我们国内用户啊

不常见

再往下，ZorinOS，是在初中学校机房的某台电脑上面见到的，我还觉得挺神奇的，能在那个地方见到个Linux系统.

总结上面就是如今我具有非常丰富的操作系统使用经验.

即使我可能没有一些大佬学到那么深层的地方去，但是10多年来的深度使用已经造就了我发现问题、判断问题、思考问题、解决问题这些步骤所需要的基础知识支撑.

所以，这篇文章并不是我想当传教士告诉你应该用Linux

我自己的看法是，操作系统永远只是一个工具，对于使用者来说，最适合自己的，最趁手的工具才是最好的工具.

有些地方，用操作系统的还存在什么鄙视链之类的情况，但实际上，哪个系统用的趁手就是选择哪个系统.

对于我来说，我拥有丰富的Linux使用经验，同时我厌恶Windows 11引入的Windows UI 3导致的大量占用与卡顿，界面是现代化了，流畅度是下滑了，所以对于我来说，选择 Linux 是一件优化自己使用体验的同时享受开源社区带来便捷的一种途径，我愿意放弃Windows的那一刻就说明我能够解决使用Linux所要带来的问题或者是我能为一些无关紧要的问题作放弃.

所以，纯新手，Linux适合日用吗？

如果你先前没有用过Linux或者是仅仅WSL内的Linux, 没有重装过系统弄不清分区，或者是你搞不清基础命令用法什么的，我仍然不建议新手使用Linux, Windows已经用GUI为新手兜底，崩一堆奇葩的软件基本上重启也能解决，换到Linux，GUI崩了对于新手来说，完全没有兜底，你只能苦苦上网搜索或者询问.

最终，你不是把他当作工具使用，你是把他当作宝一样，这也不敢碰那也不敢碰，牵一发动全身的那种感觉始终围绕着你，何苦呢？

适合自己工作环境、能够提升自己工作效率的操作系统，一间对于新手来说近乎完美的精装房，为什么你要选择抛弃他而无脑进入另一个只砌好了砖头的小屋？最后只能是经过一番折腾，小屋彻底被干成了茅厕，何苦呢？

有些人可能说，现在的Linux安装界面都是GUI，方便的一批，就算 Arch Linux 只有CLI，但是还有一键安装的 archinstall 脚本，新手上手难度怎么可能高.

但实际上，新手们对分区、磁盘格式、ROOT权限、引导什么的一窍不通，多少人连安装个Ubuntu什么都不会配置，就算最简单的国产Deepin操作系统，连安装个软件都是只会去系统预装的应用商店，指望他们去用archinstall？大部分见到那个黑漆漆的安装界面只会蒙圈然后又是一顿问，虽然AI时代下没那么难就是了…

再下来，配置输入法先查资料，问AI,半天才能配置好输入法.

往后，想美化界面？时不时GUI界面就被美化崩了，此时他们会做什么？一般来说，他们不会使用CLI的话就只会去再次重装.

但到后头的专有平台软件缺失呢？比如只有deb包没有arch的tar.zst呢？你要指望新手靠AI完全熟悉整个操作系统吗？你要指望AI能完全没有坑等着新手吗？

那么，具备一些认知经验，或者运维等之类的呢？

如果你愿意放弃Windows给你的便利，你倒是确实可以来Linux阵营试试，当然，一切必须以你的工作环境、效率、是否趁手为主.

前段时间见到有大佬教 Arch Linux 的用户怎么美化，所推荐的那个Niri, 界面是好看没得说，可他的操作逻辑意味着你要放弃长时间的Windows累积下来的操作习惯，难免会有些不适，所以，假设你真的想换到Linux,我第一推荐绝对不可能是Niri而是KDE，自由度高的同时压根不需要更改任何操作逻辑.

KDE本身就是比那堆奇奇怪怪的桌面环境来得简洁易用且干净，完全没必要去为了那点美观牺牲掉用户体验最终搞得整个系统不稳定，体验感还差.

说回日用，讲讲我的 Arch Linux

如果你决心想用Linux，那么日用一定会是你最关心的问题.

这里只以Arch Linux作为例子，DEB系包很多完全可以自己找

对于我来说，我的日用应用基本是下面这堆.

社交通讯

  • QQ微信在Arch系上AUR是有包的，可以很方便地直接使用yay安装这些包.
  • 当然，还有个软件安装的地方就是系统自带的Discover商店，里面也会有这些软件.
  • 飞书的话，同样是AUR有包，yay安装就解决了.
  • 腾讯会议？AUR
  • 云湖的话官网有Linux的deb包，使用debtap转包为tar.zst然后pacman -U就能完成安装.
  • 企业微信则是在Spark Store找到的wine版.
  • 想在电脑上装酷安，最好的方式是安装Waydroid，这个网上有教程完全可以模仿安装，AUR也有包，概不赘述.

代码编辑

  • 如果是普通的编辑器，用来应急用的，我推荐的就是KDE套件的Kate.
  • 然后就是写代码的，Visual Studio Code在AUR有包
  • Android Studio在AUR也有包
  • 同样，TraeCN-IDE在AUR也有包

视频影音

对于我来说，不能缺的绝对是B站和酷狗音乐概念版

  • 由于官方B站Linux适配版其实看着蛮臃肿的同时在Linux上有BUG，所以我选择了Piliplus作为我的Linux版B站代替，非常滴好用（）

  • 音乐的话，我选择的是EchoMusic, AUR已经有包了，非常滴好用（）

KDE套件

如果你想要其他实用工具，推荐到KDE Store看看，那边有各种为Linux设计好的KDE套件应用，非常舒服

AppImage管理

Linux上常见有种包的格式叫做AppImage，这种包打开能直接用，但是因为只能打开直接用，所以他是没法像MacOS那样安装流程时将软件复制到访达之类的操作.

但如今，Gear Lever是可以实现这一操作的，将AppImage移动到专有目录并添加到应用程序列表.

应用在系统商店 Discover 是可以搜到的，可以从 Discover 中安装.

下载器&浏览器

我已脱离Microsoft的所有东西，所以浏览器我选择了FireFox & Google Chrome（AUR同样有包），下载器Ghost Downloader是个不错的选择.

游戏

我只玩Minecraft与OSU!，所以这方面挺好解决的，OSU!用AppImage，MC用HMCL就好了

终端

最终放弃了Konsole，转向了Kitty，因为里面的某个动画太吸引我了（）

如果我想要一些其他软件，我该怎么检查他们是否在AUR存在？

其实很简单，搜索应用搜软件的后面加个AUR，有的话对应软件包名就知道了.

KDE美化？

  • 频谱图插件：Kurve
  • 面板美化：Panel Colorizer
  • 窗口模糊：kwin-effects-better-blur-dx-git (yay安装时应当使用git版来适配当前的KDE版本)
  • 窗口半透明需要到KDE设置->窗口管理->窗口规则中自己调配，具体网上也是有教程的，概不赘述.

Arch优化？

  • 如果默认调配的Swap过少（4GB及以下），你需要根据网上的教程修改下Swap减少运存占满时导致的死机.
  • 如果觉得默认的防火墙firewalld难用，请 sudo pamcan -Rns firewalld 并 sudo pacman -S ufw gufw 然后重启，使用ufw管理防火墙规则.
  • 如果你觉得应用满足不了需求，请配置wine、虚拟机或者换回Windows，MacOS等.
  • 推荐将默认的shell改为zsh,同时安装oh-my-zsh,同样的网上很多教程概不赘述了

总结

对于新手、普通电脑用户来说，我并不推荐使用Linux日用，即使现在Linux完全可以日用.
对于老鸟们，如果讨厌Windows的卡，推荐转到Linux获取更佳的操作系统使用体验.

当然，还是那句话，一切以最趁手、最适合自己为主，优化效率才是你使用操作系统的目的地而不是去站队、装杯、拉踩、对骂什么的.
